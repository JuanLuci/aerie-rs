What it is

Written from specs.
Checked against the wire.

Aerie is both sides of the game, written as one Rust codebase. Every behaviour is described first, in our own words: packet layouts, ordering, rules and formulas. The code is written from those descriptions.

The packet layouts come from a machine-readable table you generate once from your own copy of the game. Aerie's generator turns it into Rust, and real traffic, captured and re-encoded, has to come back byte for byte.

Your own copy

You need to own Hytale. Aerie logs in with your account and reads assets from your own installation. It never downloads or shares game files.

Linux, Windows and phones

One codebase. The phone is the point: the game and its server on one device, with no PC behind it.

Our own code

Specs first, in our own words, then our own code. No game code, and no material from the Hytale Shared Source programme.

How it's built

Made to work with the game,
never around it.

Aerie is an independent reimplementation. We study how the official server behaves, describe it in our own words, and write our own code with our own structure. Nothing is copied from the game.

The protocol and asset tables the build needs are generated on your machine, from your own copy of the game. This follows the interoperability provision of the Hytale EULA. Aerie has not accepted, and uses no material from, the Hytale Shared Source programme.

What Aerie does not do

  • It does not bypass login, anti-cheat or any access control.
  • It does not give anyone an advantage over the official client. It sends the same kind of traffic the official client sends.
  • It does not work without the game. You need to own Hytale.
  • It does not ship game files. Assets are read from your own installation and are never distributed.
  • It contains no game code and no game data.

FAQ

Questions

Is it legal?+

Aerie is our own code, written to interoperate with Hytale, as the Hytale EULA's interoperability provision allows. It ships no Hytale code or files and gets around no protection. We are not lawyers, and this is not legal advice.

Do I need to own Hytale?+

Yes. Aerie logs in with your own Hytale account and reads the game's assets from your own installation. Without the game it does nothing.

Will it run on my phone?+

That is the goal: client and server on the phone, no PC needed. Not yet, though: the server on a phone is one of the next steps, and the client has not been started.

Is it official?+

No. Aerie is a fan project with no connection to Hypixel Studios. They don't endorse or support it, so please don't send them Aerie problems.

Can I play on it now?+

Only to try it. You build the server from source, then join a generated world with the official client: walk, build, craft, chat. Survival mechanics, creatures and real world generation are not there yet. See the climb so far and the source on GitHub.
